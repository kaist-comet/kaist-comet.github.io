# comet.kaist.ac.kr

To install:
https://jekyllrb.com/docs/installation/macos/

To run the web server on your local machine:
```
bundle exec jekyll serve
```


# How to Update

* `_data/members.yml` - COMET member profiles
* `_data/pub_non_comet.yml` - If any COMET member has publications before joining COMET, they will not appear in the publications page. But those publications can appear in the member profiles. This yml file is for such cases.

* The publications page is updated by Dr. Kwon's CV update automatically. No manual edit.
